# Extra flag patterns (extended regex, one per line, matched case-insensitive).
# Lines starting with '#' are ignored. These are searched in every file
# (binary included). A generic "<word>{...}" pattern is always applied on top,
# but only to printable text (strings / exiftool / zsteg / text files).
#
# Override or add at runtime:  ./ctf triage <file> --pattern 'MYFLAG\{[^}]+\}'
